# 页面 2：Agent 对话

> 路径：`/projects/:id/agent`
> 优先级：**P0 - 核心页面**。这是用户最主要的工作界面，所有写作活动通过对话完成。

## 2.2 顶部栏

高度约 48px，内容左右分布：

**左侧**：
- 项目名称（16px 字重 600）
- 绿色圆点（6px）+「在线」文字（12px）— 表示 Agent 服务可用

**右侧**：
- 「🔄 新会话」按钮（文字按钮，灰色）
  - 点击 → 弹出确认「清除当前对话并开始新会话？」
  - 确认后清除消息列表但保留项目数据

**分隔线**：1px 浅灰

## 2.3 消息列表

滚动区域，占对话区大部分空间。消息从底部排列，最新的在最下面，自动滚到底部。

```

```

- 工具结果返回后，Agent 继续输出

### 2.3.5 工具调用卡片

当 Agent 调用工具时，消息流中插入工具卡片：

```
┌─────────────────────────────────────┐
│  📖 正在读取第3章...                 │
│                                     │
│  ● read_chapter                     │
│    ├─ 参数: chapter_index: 3        │
│    └─ 状态: ⏳ 执行中               │
│                                     │
│  ○ query_world                      │
│    └─ 状态: ⏳ 排队中               │
└─────────────────────────────────────┘
```

工具执行完成后，卡片更新：

```
┌─────────────────────────────────────┐
│  📖 已查阅 2 个数据源               │
│                                     │
│  ✅ read_chapter                    │
│    └─ 第3章「迷雾」- 28字           │
│                                     │
│  ✅ query_world                     │
│    └─ 林思 (配角) - 来自档案局      │
└─────────────────────────────────────┘
```

**工具卡片设计规则：**

| 状态 | 图标 | 颜色 | 说明 |
|------|------|------|------|
| 排队中 | ○ | 灰色 | 等待执行 |
| 执行中 | ● | 蓝色 | 正在运行，有旋转动画 |
| 成功 | ✅ | 绿色 | 完成 |
| 失败 | ❌ | 红色 | 执行出错 |
| ⚠️ 工具不存在 | ❌ | 红色 | Agent 幻觉，请求了不可用的工具 |
| 🔒 需批准 | 🔒 | 琥珀色 | 写入操作等待用户审批 |

- 卡片白底浅灰边框
- 圆角 8px
- 内边距 12px
- 工具名使用等宽字体 13px
- 参数和结果显示为灰色小字 12px
- 多个工具调用逐个展开，已完成的状态固定，当前执行的动效指示

当 Agent 发起写入操作（写章节、改设定等）时出现：

```
┌──────────────────────────────────────────┐
│  🛡️ 审批请求                             │
│                                          │
│  Agent 想要执行以下操作：                 │
│                                          │
│  ✍️ 写入 第4章「黑潮门」                 │

│                                          │
│  ┌────────────────────────────────────┐  │
│  │ 林思的出现让地下室的气氛骤然...    │  │
│  │ 她穿着灰色制服，胸口的工牌...     │  │  ← 内容预览（可滚动）
│  │ ...                               │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ┌──────┐         ┌──────────────────┐  │
│  │ ❌ 拒绝 │         │ ✅ 批准并执行    │  │
│  └──────┘         └──────────────────┘  │
│                                          │
│  拒绝时可填写理由：                       │
│  ┌────────────────────────────────┐      │
│  │ (选填)                          │      │
│  └────────────────────────────────┘      │
└──────────────────────────────────────────┘
```

**审批卡片设计规则：**

| 元素 | 规格 |
|------|------|
| 背景 | 琥珀色 (#F59E0B 8% 透明度) |
| 边框 | 琥珀色 (#F59E0B) |
| 图标 | 🛡️ 盾牌 20px |
| 标题 | 「审批请求」16px 字重 600 |
| 工具名 | 等宽字体 14px |
| 内容预览 | 最大高度 120px，可滚动 |
| 批准按钮 | 绿色 #10B981，白字，圆角 6px |
| 拒绝按钮 | 白色，红字红色边框 |
| 理由输入 | 折叠在「拒绝」按钮下方，点击拒绝按钮时展开 |

**交互流程：**
1. 卡片出现 → 对话流暂停（Agent 等待）
2. 用户点击「批准」→ 卡片变为绿色已批准状态 → Agent 继续
3. 用户点击「拒绝」→ 展开理由输入框 → 填写理由（可选）→ 确认拒绝 → 卡片变为红色已拒绝 → Agent 收到拒绝理由并调整
4. 对话流在审批期间保持可见，用户可滚动查看历史

已审批/已拒绝的卡片状态：

```
┌─────────────────────────────────┐
│  ✅ 已批准 · 第4章「黑潮门」     │  ← 绿色背景
│  内容已写入                      │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│  ❌ 已拒绝 · 第4章「黑潮门」     │  ← 红色背景
│  理由: 章节顺序不对              │
└─────────────────────────────────┘
```

## 2.4 输入区

底部固定区域：

```
┌──────────────────────────────────────┐
│                                      │
│  ┌──────────────────────────┐  ┌──┐  │

│  提示：支持自然语言，如"写第4章"      │
│  "查一下林舟的设定"                   │
└──────────────────────────────────────┘
```

| 元素 | 规格 |
|------|------|
| 文本输入框 | 多行（最大 4 行），无边框，圆角 8px 灰边框 |
| 高度 | 40-120px（随内容自动增高）|
| 占位文字 | 「对 Agent 说点什么…」灰色 14px |
| 发送按钮 | 圆形 36px，主色蓝底白箭头图标 |
| 发送快捷键 | Enter（Shift+Enter 换行）|
| 底部提示 | 12px 浅灰，「支持自然语言」+ 示例 |

**发送按钮状态：**

| 状态 | 表现 |
|------|------|
| 空输入 | 灰色不可点击 |
| 有输入 | 蓝色可点击 |
| 发送中 | 变为 ■ 停止按钮（红色），点击中断 Agent 生成 |
| 禁用 | 灰色（Agent 正在等待审批时）|

**输入建议**：输入框聚焦时，上方可弹出快速指令建议（类似输入法候选词）：

```
┌──────────────────────────────┐
```

## 2.7 加载 / 错误 / 边界状态

### Agent 连接中

```
┌─ 顶部栏 ──────────────────────────┐
│  ⚡ 正在连接 Agent 服务...         │  ← 蓝色横幅
└────────────────────────────────────┘
```

### 网络断开

```
┌─ 顶部栏 ──────────────────────────┐
│  ⚠️ 连接断开，正在重试... (3s)    │  ← 红色横幅，倒计时
└────────────────────────────────────┘
```

- 重试间隔：3 秒
- 超过 30 秒：显示「连接失败，请检查网络」+ 手动重试按钮

### 消息发送失败

```
┌──────────────────────────────┐
│  用户消息 (灰色半透明)        │
│                      ❌ 发送失败 │  ← 红色 + 可点击重试
└──────────────────────────────┘
```

- 失败的消息保持可见
- 右侧显示红色「发送失败」，点击重发

### API Key 未配置

- 如果 API Key 未配置：对话页面顶部显示黄色横幅
- 「⚠️ 尚未配置 AI 模型 API Key → 前往设置」

### 生成长文本

- 打字机效果持续，Agent 可能生成数百字
- 用户可随时点击输入框旁的 ■ 停止按钮中断 Agent
- 中断后 Agent 会输出已生成的部分

### 碎片化 / 短内容

- 如果 Agent 回答极短（如只回答「好的」），消息气泡正常显示
- 不打断对话流
