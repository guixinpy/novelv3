# 用户流程：完整交互场景

> 本文档描述用户在关键场景中的完整操作流程和页面反应。

---

## 流程 1：首次使用 — 创建项目并开始写作

```
步骤                                 页面反应
────                                  ──────
1. 打开应用                          → 项目列表（空状态）
                                     显示引导：「还没有项目」
2. 点击「+ 创建第一个项目」          → 弹出新建对话框
3. 输入「雾港谜案」，选「悬疑」      → 按钮激活
4. 点击「创建」                      → 跳转到 Agent 对话页面
                                     显示欢迎消息 + 4 个示例卡片
5. 点击示例卡片「帮我生成世界观设定」 → 输入框填入文字
6. 按 Enter 发送                     → 消息出现在对话区（右对齐）
                                     Agent 开始打字
                                     工具卡片出现（生成设定中…）
                                     工具执行完毕 → Agent 输出设定结果
7. 输入「写第一章」                  → Agent 生成章节目录
                                     Agent 调用 write_chapter
                                     审批卡片出现（琥珀色）
8. 预览内容，点击「批准」            → 卡片变为绿色「已批准」
                                     章节写入完成
                                     Agent 输出确认消息
                                     右侧面板章节数 +1
```

## 流程 2：检查章节一致性

```
步骤                                 页面反应
────                                  ──────
1. 在对话页面输入                    → 消息出现在对话区
   「看看第3章和林思有没有矛盾」
2. 等待 Agent 响应                   → Agent 依次调用工具：
                                     ✅ read_chapter(第3章)
                                     ✅ query_world(林思)
                                     ✅ query_memory(林思)
                                     每个工具完成，卡片绿色
3. Agent 输出分析结果                → 文本出现在对话区
                                     「第3章中林思只是出现…
                                      当前不存在明显矛盾」
                                     工具摘要显示在消息下方
4. 查看右侧面板                      → 工具调用历史更新
                                     记忆摘要显示「林舟」「林思」
```

## 流程 3：修改世界观设定（含审批）

```
步骤                                 页面反应
────                                  ──────
1. 输入「把林思改成来自外地」        → 对话显示用户消息
2. Agent 分析变更                    → query_world(林思)
                                     阅读当前设定
3. Agent 发起变更                    → propose_world_change 被调用
                                     🔒 审批卡片出现
                                     显示变更内容预览
4. 点击「批准」                      → 卡片变绿「已批准」
5. Agent 执行变更                    → update_setup 被调用
                                     输出确认「林思的背景已更新」
                                     右侧面板记忆更新
```

## 流程 4：Agent 异常 — 护栏触发

```
步骤                                 页面反应
────                                  ──────
1. Agent 陷入循环（连续调用同一工具） → 护栏检测触发
2. 系统自动拦截                      → 对话中出现红色警告卡片
                                     ⚠️ 护栏触发 · L1 重复调用
                                     「连续 3 次调用相同工具」
3. Agent 自动恢复                    → Agent 调整策略
                                     输出「我换个方式试试」
                                     改用其他工具继续
4. 右侧面板                          → 护栏状态区域出现
                                     显示已触发的规则
                                     用户可查看详情
```

## 流程 5：浏览章节

```
步骤                                 页面反应
────                                  ──────
1. 点击边栏 📖 图标                  → 切换到章节库页面
                                     显示章节列表
2. 滚动浏览                          → 查看所有章节
                                     状态标签清晰可见
3. 点击「第4章 黑潮门」              → 阅读视图展开
                                     显示完整正文
4. 阅读完毕，点击「返回章节列表」    → 回到列表视图
```

## 流程 6：查阅世界设定

```
步骤                                 页面反应
────                                  ──────
1. 点击边栏 🌐 图标                  → 切换到世界观页面
                                     默认显示人物 Tab
2. 点击「林舟」卡片                  → 详情面板滑出
                                     显示完整设定
3. 切换「情节线」Tab                 → 显示情节线列表
                                     开放中 / 已闭环分组
4. 点击「前往对话」按钮              → 跳转到对话页面
                                     输入框填充「帮我修改设定」
```

## 流程 7：网络断开与重连

```
步骤                                 页面反应
────                                  ──────
1. 网络断开                         → 对话页顶部显示红色横幅
                                     「连接断开，正在重试…」
2. 等待 3 秒                        → 自动重试
3. 重连成功                          → 横幅消失
                                     显示绿色消息「连接已恢复」
4. 若 30 秒仍失败                   → 横幅变为
                                     「连接失败，请检查网络」
                                     显示手动重试按钮
5. 用户点击重试                     → 重新尝试连接
```

## 流程 8：API Key 配置

```
步骤                                 页面反应
────                                  ──────
1. 进入项目 / 对话页面               → 顶部黄色横幅
                                     「⚠️ 尚未配置 AI 模型 API Key」
2. 点击横幅或进入设置页              → 跳转到设置页面
                                     输入框为空，状态🔴 未配置
3. 粘贴 API Key                      → 输入框显示 ●●●
                                     「保存」按钮激活
4. 点击「保存」                      → 按钮变为「⏳ 验证中…」
5. 验证成功                          → 🟢 已配置
                                     Toast「API Key 已保存」
6. 返回对话页面                      → 横幅消失
                                     可以正常对话
```
