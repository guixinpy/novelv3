## 3.2 顶部信息栏

- 标题「章节」24px
- 统计信息：「共 N 章 · 总计 M 字」14px 灰色
- 右侧可以有一行批量操作（如果需要，如「全部导出」）

## 3.3 章节列表

纵向列表，每行高度约 56px，带 1px 浅灰底部分隔线。

### 行结构

```
 01 │ 第一章 潮雾    ✅ 已完成  380字  │  ↗
序号 │ 标题          状态标签    字数   │ 进入阅读
```

| 列 | 宽度 | 内容 |
|----|------|------|
| 序号 | 40px | 两位数字（01/02/…），大字 20px 字重 700 浅灰 |
| 标题 | 弹性 | 16px，已完成为黑色，未开始为浅灰 |
| 状态 | 80px | 标签样式（见下表） |
| 字数 | 60px | 14px 灰色右对齐 |
| 阅读 | 40px | → 箭头图标，悬停显示 |

### 状态标签

| 状态 | 视觉 |
|------|------|
| ✅ 已完成 | 绿色底白字标签（或绿点+文字）|
| ⏳ 生成中 | 蓝色底 + 旋转动画 |
| ⬜ 未开始 | 灰色虚线 + 浅灰文字 |
| ❌ 失败 | 红色底白字（极少出现）|

### 交互

- **整行可点击** → 进入阅读视图
- **悬停**：行背景变为浅蓝灰色 (#F8FAFC)
- **拖拽排序**：可选（如果支持手动调整章节顺序）

### 阅读视图布局

| 区域 | 说明 |
|------|------|
| 面包屑 | 项目名 > 第X章 标题，14px 灰色，可点击返回 |
| 标题 | 居中，24px，字重 700，上下间距 24px |
| 正文 | 18px 行高 1.8，最大宽度 720px，居中 |
| 元数据 | 14px 灰色，显示字数、题材、生成时间 |
| 返回按钮 | 文字按钮「← 返回章节列表」|

### 阅读视图交互

- 正文区域左右留白充足（舒适阅读宽度）
- 长章节支持滚动
- 可选暗色模式（阅读模式切换按钮）
- 页面底部显示「上一章」「下一章」导航按钮

## 3.7 边界状态

- **章节正在生成中**：状态显示 ⏳ 生成中，点击不可阅读
- **章节生成失败**：状态显示 ❌ 失败，点击可查看错误信息
- **字数过多**（>50000）：显示「超长章节」标记
- **无标题章节**：标题显示为「第X章（未命名）」
