## 4.4 Tab：人物

### 人物卡片网格

2-4 列响应式网格。每张卡片：

```
┌───────────────────┐
│                   │
│      👤           │  ← 头像占位（首字母或默认图标）
│                   │
│   林舟             │  ← 16px 字重 600
│   🟢 主角 · 存活   │  ← 12px 标签
│                   │
│  谨慎 · 敏锐       │  ← 核心特质标签
│                   │
│  📍 雾港城旧灯塔   │  ← 当前位置 12px 灰色
│                   │
└───────────────────┘
```

**卡片尺寸**：约 200px 宽 × 180px 高

**核心特质**：显示为小标签 pills，最多 3 个

**状态指示**：
- 🟢 存活 - 绿色
- 🔴 已故 - 红色
- ⚫ 失踪 - 灰色
- 💀 死亡 - 黑色

## 4.6 Tab：情节线

### 列表视图

```
┌────────────────────────────────────────────┐
│  🧵 林舟父亲失踪之谜              🔓 开放中  │  ← 开放置顶
│  林舟的父亲在灯塔火灾中失踪……                │
│  第1章 → 进行中                             │
├────────────────────────────────────────────┤
│  🧵 黑潮门的秘密                  🔓 开放中  │
│  旧灯塔地下隐藏着黑潮门……                   │
│  第3章 → 进行中                             │
├────────────────────────────────────────────┤
│  🧵 档案局的阴谋                  🔒 已闭环  │  ← 已闭环灰色
│  档案局封存了关键证据……                     │
│  第1章 → 第5章                              │
└────────────────────────────────────────────┘
```

**每行结构：**

| 列 | 内容 |
|----|------|
| 图标 | 🧵 |
| 标题 | 16px 字重 600，闭环灰色 |
| 状态标签 | 🔓 开放中（蓝色）/ 🔒 已闭环（灰色）|
| 摘要 | 14px 灰色，单行省略 |
| 章节范围 | 第N章 → 第M章 |

**交互：**
- 开放中的情节线置顶，已闭环的排后
- 点击行展开详情（或跳转详情页）
- 点击章节数字可跳转到对应章节
