# 页面 1：项目列表

> 路径：`/`
> 唯一用途：选择或创建一个项目，然后进入 Agent 对话页面。

---

## 1.1 页面布局

```
┌───────────────────────────────────────────────────┐
│  边  ┌────────────────────────────────────────────┐│
│  栏  │  墨舟 AI Writer                            ││
│      │  AI 辅助长篇网文创作                       ││
│  💬  │                                            ││
│  📖  │  ┌──────┐ ┌──────┐ ┌──────┐              ││
│  🌐  │  │项目A  │ │项目B  │ │项目C  │              ││
│  ⚙️  │  │悬疑   │ │奇幻   │ │科幻   │              ││
│      │  │1.2万字│ │0.8万字│ │2.5万字│              ││
│      │  │今天   │ │昨天   │ │3天前  │              ││
│      │  └──────┘ └──────┘ └──────┘              ││
│      │                              [+ 新建]    ││
│      └────────────────────────────────────────────┘│
└───────────────────────────────────────────────────┘
```

## 1.2 顶部区域

- **应用名称**：「墨舟 AI Writer」— 24px 字重 600
- **副标题**：「AI 辅助长篇网文创作」— 14px 灰色
- 上下间距：顶部 48px，标题和网格之间 32px

## 1.3 项目卡片网格

- 2-3 列网格，卡片等宽
- 每张卡片尺寸：约 280-320px 宽 × 160px 高
- 卡片内容：

```
┌──────────────────┐
│ 🎭 项目名称      │  ← 16px 字重 600
│ 悬疑             │  ← 12px 标签(圆角矩形)
│                  │
│ 1.2万字 · 10章   │  ← 14px 灰色
│ 最后编辑: 今天   │  ← 12px 灰色
│                  │
│ 📊 写作进度      │  ← 进度条
│ ████████░░ 80%   │
└──────────────────┘
```

### 卡片状态

| 状态 | 表现 |
|------|------|
| **正常** | 白底，浅灰边框，轻微阴影 |
| **悬停** | 上浮 2px，阴影加深，边框变为主色 |
| **点击** | 缩小动画 → 跳转到项目 |
| **空白（未写入）** | 显示「新建项目」占位提示，进度条为空 |
| **写作中** | 进度条部分填充，显示当前字数 |
| **已完成** | 进度条填满，显示 ✅ 标记 |

### 写作进度条

- 浅灰底色条（高 6px，圆角）
- 蓝色填充条表示完成度
- 右侧显示百分比数字

## 1.4 新建项目

### 浮动按钮

- 右下角固定位置
- 圆形蓝色按钮（48px），内含「+」图标
- 点击弹出「新建项目」对话框

### 新建项目对话框

```
┌──────────────────────┐
│  新建项目            │  ← 标题 20px
│                      │
│  项目名称 *          │
│  ┌────────────────┐  │
│  │                │  │  ← 输入框 16px 高度 40px
│  └────────────────┘  │
│                      │
│  题材                │
│  ┌────────────────┐  │
│  │ 请选择 ▼       │  │  ← 下拉选择框
│  └────────────────┘  │
│  (通用/悬疑/奇幻/科幻/言情/都市/历史)  │  ← 小字提示
│                      │
│       [取消] [创建]   │  ← 按钮
└──────────────────────┘
```

| 元素 | 说明 |
|------|------|
| 项目名称 | 必填，1-50 字符，实时校验 |
| 题材 | 可选下拉，默认「通用」，包含 7 个选项 |
| 取消按钮 | 关闭对话框，无副作用 |
| 创建按钮 | 创建后直接跳转到该项目的 Agent 对话页面 |

## 1.5 空状态

首次使用、没有任何项目时：

```
┌──────────────────────────────────┐
│                                  │
│          📝 (大图标 64px)        │
│                                  │
│    还没有项目                     │
│    去对话页面开始你的第一部作品    │
│                                  │
│  ┌──────────────────────────┐    │
│  │  + 创建第一个项目         │    │
│  └──────────────────────────┘    │
│                                  │
└──────────────────────────────────┘
```

- 图标居中，64px
- 标题「还没有项目」16px 灰色
- 副标题 14px 浅灰
- CTA 按钮「创建第一个项目」— 主色蓝底白字

## 1.6 加载状态

- 首次加载时：3 个灰色骨架卡片（Skeleton Loading）占位
- 骨架卡片：浅灰渐变背景，模拟卡片形状在闪烁

## 1.7 错误状态

- 项目加载失败：显示错误提示 + 「重试」按钮
- 网络断开：显示红色横幅「网络连接断开」
