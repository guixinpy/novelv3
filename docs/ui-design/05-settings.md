## 5.2 设置卡片

- 白底卡片，8px 圆角
- 标题「AI 模型」16px 字重 600
- 内边距 20px

### API Key 输入

| 元素 | 规格 |
|------|------|
| 标签 | 「API Key」14px 字重 500 |
| 输入框 | 宽度 100%，高度 40px，圆角 6px，边框灰 |
| 输入类型 | password（显示为圆点）|
| 占位文字 | 空状态显示「输入 API Key」|
| 切换可见 | 输入框右侧有 👁️ 图标，点击切换明文/密文 |

### 状态指示

输入框下方：

| 状态 | 视觉 |
|------|------|
| 🟢 已配置 | 绿色文字，显示 Key 的前 8 位 |
| 🔴 未配置 | 红色文字「尚未配置 API Key」 |
| ⏳ 验证中 | 灰色 + 旋转动画「正在验证…」 |

### 保存按钮

- 主色蓝底白字
- 点击保存后「正在验证…」→ 验证成功显示 🟢 / 失败显示 🔴
- 保存后 Key 不显示完整，仅显示前 8 位

### 说明文字

- 12px 灰色
- 「API Key 用于调用 AI 模型，仅存储在本地设备上」

---

## 5.3 空状态（首次进入）

- 输入框为空，显示占位文字
- 状态显示🔴 未配置
- 保存按钮文字：「保存并验证」

---

## 5.4 交互流程

1. 用户粘贴 API Key 到输入框
2. 点击「保存」
3. 按钮变为「⏳ 验证中…」灰色禁用
4. 后端验证 Key 有效性
5. 成功 → 🟢 已配置，按钮恢复
6. 失败 → 🔴 验证失败 + 错误提示「Key 无效，请检查后重试」
